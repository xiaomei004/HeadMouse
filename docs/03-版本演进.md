## v1.0（2026-11-05）

修的都是"用起来才知道"的问题：

1. **单击/双击计数无区别** → 拆成 `clicks_single` / `clicks_double`，
   总点击数 = 单 + 双×2，界面 `clicks:总 (S单/D双)`。
2. **停住只计一次点击** → 保留该行为（dwell click 必须的防连点），
   但把 `armed` 状态可视化：`move:xx/90 px  LOCKED/ARMED`，
   并改用**净位移**判断重新武装（累计路程会被手抖刷满，导致连点）。
3. **按空格后光标跳到屏幕中心** → 原点改为"按下开始时的光标位置"
   （`GetCursorPos`），按下前后零位移；新增 `O` 键重取原点、`--origin center` 保留旧行为。
4. **小窗口时光标仍绕屏幕中心运动** → 同 3，坐标系从屏幕中心改为光标原点；
   多显示器用虚拟桌面矩形做边界。
5. **窗口失焦后鼠标被锁死，只能关机** → 三道闸：
   `F8`/`F12` 全局急停（`GetAsyncKeyState`，与焦点无关）、
   人工接管自动暂停（设置光标前比对 `GetCursorPos`，阈值 90 px）、
   原点不再强制回屏幕中心。
6. **只有位置映射，不能"一直往一个方向走"** → 新增**速度映射**（`T` 键切换），
   偏移量当油门，`VMAX = 1500 px/s`。

附带改进：

- 检不到脸时**冻结**光标（此前会去跟踪背景纹理，光标乱飞），2.5 秒后自动暂停
- 开始后必须先动 90 px 才允许第一次点击，消除"按空格瞬间误点"
- 底部信息条重排，进度条不再压住文字；新增 `--snapshot` 存带叠层的截图
- 文档体系：README + 技术方案 + 排查记录 + 版本演进 + 实验对照
