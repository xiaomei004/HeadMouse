# 版本演进

时间：2026-11-05（实验当天，从零到可用共 8 个迭代）

| 版本 | 变更 | 触发原因 |
|---|---|---|
| v0.1 | 摄像头 + Haar/固定 ROI 角点 + 平均值位移 + 线性映射 | 探路：验证"光流能测头动" |
| v0.2 | 改用 YuNet 人脸检测；在脸框内撒点 | Haar 模型缺失；背景点把位移平均成 0 → 慢、只往左上 |
| v0.3 | 位移改取**中位数**；前后向校验剔除外点 | 少数跑飞点的平均值污染了结果 |
| v0.4 | 加入**脸框锚定融合**（`BETA = 0.12`） | 光流累计误差，静置 10 s 漂移 165 px |
| v0.5 | 死区 `DEAD = 1.6` + EMA `SMOOTH = 0.3` | 静止时抖、误点 |
| v0.6 | 停留点击 + 冷却 + 重新武装（净位移 90 px） | 停在原地被连续点击 |
| v0.7 | 单击/双击双模式；双击间隔跟随系统 | 实验要求"实现单击、双击" |

| v0.9 | 打包启动脚本、模型内置；`--no-mouse` | 交付/演示要一键能用（本仓库基线提交） |
| **v1.0** | 见下 | 根据实机使用反馈修的 6 个问题 |

## v1.0（2026-11-05）

修的都是"用起来才知道"的问题：

1. **单击/双击计数无区别** → 拆成 `clicks_single` / `clicks_double`，
   总点击数 = 单 + 双×2，界面 `clicks:总 (S单/D双)`。
2. **停住只计一次点击** → 保留该行为（dwell click 必须的防连点），
   但把 `armed` 状态可视化：`move:xx/90 px  LOCKED/ARMED`，
   并改用**净位移**判断重新武装（累计路程会被手抖刷满，导致连点）。
3. **按空格后光标跳到屏幕中心** → 原点改为"按下开始时的光标位置"
   （`GetCursorPos`），按下前后零位移；新增 `O` 键重取原点、`--origin center` 保留旧行为。
4. **小窗口时光标仍绕屏幕中心运动** → 同 3，坐标系从屏幕中心改为光标原点；
   多显示器用虚拟桌面矩形做边界。
5. **窗口失焦后鼠标被锁死，只能关机** → 三道闸：
   `F8`/`F12` 全局急停（`GetAsyncKeyState`，与焦点无关）、
   人工接管自动暂停（设置光标前比对 `GetCursorPos`，阈值 90 px）、
   原点不再强制回屏幕中心。
6. **只有位置映射，不能"一直往一个方向走"** → 新增**速度映射**（`T` 键切换），
   偏移量当油门，`VMAX = 1500 px/s`。

附带改进：

- 检不到脸时**冻结**光标（此前会去跟踪背景纹理，光标乱飞），2.5 秒后自动暂停
- 开始后必须先动 90 px 才允许第一次点击，消除"按空格瞬间误点"
- 底部信息条重排，进度条不再压住文字；新增 `--snapshot` 存带叠层的截图
- 文档体系：README + 技术方案 + 排查记录 + 版本演进 + 实验对照

## v1.1（2026-11-05 晚）

1. **光标太不显眼** → 在指针外面叠一个分层准星窗口（黑-琥珀-黑圆环 + 四向刻度），
   点击穿透、置顶、不抢焦点，`H` 键开关。
2. **速度模式一开就飞** → 线性改 `^1.5` 曲线，满速 1500 → 650 px/s，满速区 26 → 45 px；
   `1/2/3` 同时控制位置行程与速度上限（380/650/1000 px/s）。
3. 附带修一个隐蔽 bug：`mouse_event` 后立刻读坐标会读到旧值，导致速度模式下
   "人工接管"误判、一秒就自动暂停 —— 改为按增量推算 + 每帧校准 + 连续 3 帧确认。

## v1.2（2026-11-05 晚）

**触发**：同学装的 eViacam 1.7.2 同样在 Win11 上起不来，需要一个"下载就能用"的包。

1. **PyInstaller 打包 exe**：`scripts/build_release.py` 一条命令同时产出单文件版和目录版，
   自动带图标、捆绑 `models/yunet.onnx`、按版本号命名、目录版自动打成 zip。
2. **修资源路径**：源码里 `MODEL` 原来固定为"脚本目录 / models / yunet.onnx"，
   打包后 `__file__` 指向 `_MEIPASS` 临时解包目录，改为优先读 `sys._MEIPASS`，
   否则 exe 启动就报"模型未找到"、退化成固定框跟踪。
3. **保留控制台窗口**：试过 `--noconsole`，一旦相机被占用或权限没开，程序静默退出、
   同学完全不知道发生什么，于是改回带控制台（能看到 `[模型] YuNet 已加载`、报错信息）。
4. 新增 `docs/同学速用说明.txt`（随包分发）与 README「下载即用」一节。
