HeadMouse 使用说明（发给同学的那份）
=====================================

一句话：普通摄像头 + 头部运动 = 鼠标。不用装驱动，不用装 Python，解压双击就能跑。

一、准备工作（Win10 / Win11 都行）
1. 把 HeadMouse-v1.2-win64-portable.zip 解压到任意位置。
   注意：要整个文件夹一起解压，不要只把里面的 HeadMouse.exe 单独拖出来。
2. 首次双击 HeadMouse.exe，如果弹出蓝色的"Windows 已保护你的电脑"：
   点"更多信息" → "仍要运行"。这是未做数字签名的程序都会有的提示，不是病毒。
3. 如果杀毒软件报毒并删除文件，把整个文件夹加入信任/白名单再重来。
   （PyInstaller 打包的程序常被误判，源码在 GitHub 上可自行核对。）

二、确认摄像头权限
设置 → 隐私和安全性 → 相机 → 打开"相机访问"，
并确保"让桌面应用访问相机"是开着的。否则程序会提示打不开摄像头。

三、开始使用
1. 双击 HeadMouse.exe，等 3 秒左右出现"HeadMouse"摄像头窗口。
2. 画面里出现黄色人脸框和 FACE 0.9x 的字样，说明认出你的脸了。
   （没有框就把脸摆正、离摄像头 50~70 cm、光线别太暗，可左右晃晃）
3. 按【空格】开始。此时鼠标光标外面会出现一圈琥珀色准星，方便你找到它。
4. 头往哪边偏，光标就往哪边走。头部回正，光标回到按空格时的位置。
5. 停住不动约 0.8 秒 = 单击一次（屏幕左下角有进度条）。
   点完之后要先移动一段距离，才能触发下一次点击——这是故意设计的，
   否则你停在那里会不停地连点。

四、常用按键（窗口在前台时）
   空格        开始 / 暂停
   C           重新锁定（脸摆正后按一次，重新校准）
   O           以当前光标位置重新取原点
   T           切换 位置映射 / 速度映射
   X           切换 单击 / 双击
   1 2 3       灵敏度：低 / 中 / 高（速度模式下是 380 / 650 / 1000 px/s）
   H           开 / 关 光标准星
   F8          暂停（全局有效，窗口没在最前面也管用）
   F12         立即退出（全局有效）
   ESC / Q     退出（需要窗口在前台）

五、找不到鼠标 / 鼠标被锁住怎么办
按 F8 立刻暂停并把鼠标还给你，按 F12 直接退出。这两个键在任何情况下都有效，
不需要窗口在前台。这是专门防"程序抢了鼠标动不了"的。

六、手感调整
- 觉得太灵敏、光标晃：按 1（位置模式行程 260 px）
- 觉得够不到屏幕边缘：按 3（行程 100 px）
- 想要"头偏一边光标一直走"：按 T 切到速度映射，用 1/2/3 调快慢
- 长时间用建议速度映射，位置映射需要一直保持偏头姿势，脖子会累

七、已知限制
- 只支持 Windows（用到了 Win32 的 SetCursorPos / 分层窗口）
- 睁不开眼、戴帽子遮额头、逆光等情况会影响人脸检测
- DirectX 独占全屏的游戏里准星可能不显示（不影响控制）
- 摄像头被其他软件占用（腾讯会议、OBS 等）时会打不开，先关掉它们

八、它和 eViacam 有什么关系
课程要求装的 eViacam 1.7.2 在 Win11 上很多机器一启动就崩
（APPCRASH 0xc0000005，MSVCR90.dll），这是它自带的老版 VC 运行库和
Win11 冲突，重装/兼容模式都救不回来。这个程序是同功能的替代实现：
一颗摄像头，不依赖任何系统级驱动，一个 exe 就能跑。

源码与详细原理：https://github.com/xiaomei004/HeadMouse
